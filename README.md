# Featured Projects

##  Mini Automated Cyber Security Operations Center (CSOC)

A practical automated Security Operations Center lab built using **Wazuh SIEM, Ubuntu Server, Windows, Kali Linux, n8n, and Telegram**.

The project demonstrates centralized security monitoring, custom threat detection, automated incident response, security alert automation, and dashboard-based investigation.

### Key Features

- Centralized security monitoring using **Wazuh SIEM**
- Windows and Linux security event monitoring
- Custom Wazuh detection rules
- SSH authentication failure detection
- SSH brute-force attack detection
- Windows brute-force detection
- Windows Firewall event monitoring
- Suspicious PowerShell activity detection
- File Integrity Monitoring (FIM)
- MITRE ATT&CK mapping
- Automated incident response using **Wazuh Active Response**
- Automatic SSH brute-force attacker IP blocking
- High-severity alert automation using **n8n**
- Automated security notifications through **Telegram**
- Security monitoring and incident-response dashboards

### Technologies

`Wazuh` `Ubuntu Server` `Windows` `Kali Linux` `n8n` `Telegram` `VirtualBox` `PowerShell`
